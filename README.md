Fantasy Sport Web Application

https://github.com/zacharywilliams229/FantasyCollegeFootball

Fantasy Sports website for college football and baseball.

Currently only works for MLB because football is in the offseason.

View live website: http://zacharydaniel229.duckdns.org:8080

Features:
- Authentication using Google OAuth
- Create and manage multiple leagues
- Invite friends through private invite code
- Draft team live
- Manage team throughout the season
- Compete in head-to-head matchups against friends
- Climb to the top of the league leaderboard by winning the most matches
- Custom scoring
- Stat updates every thirty minutes
- Final matchups process at 10:15 a.m. CST and Roster changes push at 10:45 a.m. CST
